# Dragon Phylogeny Traits

This file is copied from the original Colautti Lab Dragon Phylogeny project and is included as reference for the character matrix used in Assignment 8.

The Dragon Phylogeny dataset uses a set of morphological traits that were scored from images of dragons and then encoded as binary characters for the phylogenetic analysis.

The original project and tutorial are available in the Colautti Lab Dragon Phylogeny repository.
